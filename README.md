# Public data snapshots (CC0)

Free, citable snapshots of US public-records data, read from official public APIs. Each folder has a dataset card (Hugging Face format) and a CSV.

| Dataset | Rows | Source | Fresh feed |
|---|---|---|---|
| [us-federal-grants-open](us-federal-grants-open) | 787 | Grants.gov search2 API, 2026-11-24 | [Grants.gov Scraper](https://apify.com/publicrecords/grants-gov-scraper) |
| [us-federal-awards-recent](us-federal-awards-recent) | 100 | USAspending API, 2026-11-24 | [USAspending Awards Scraper](https://apify.com/publicrecords/usaspending-awards-scraper) |

Fresh, scheduled versions run as Apify Actors from [Public Records](https://apify.com/publicrecords) (disclosure: we maintain them; pay-per-use on Apify), also usable by AI agents over MCP: see [publicrecords-mcp](https://github.com/GeminiGeorge22/publicrecords-mcp).
