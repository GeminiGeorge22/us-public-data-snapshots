# Open US Federal Grants — Grants.gov snapshot (2026-11-24)

All 787 grant opportunities with status **posted** on Grants.gov, read 2026-11-24 from the public Grants.gov `search2` API: opportunity id and number, title, agency, open and close dates, CFDA/Assistance Listing numbers and a link to each listing.

US federal government works are public domain; this snapshot is released under CC0.

## Fresh data every day
This file is a one-day snapshot.
